# Wild Rank Pipeline — Privacy Policy

Wild Rank Pipeline is an internal automation used only by the owner of the Wild Rank YouTube channel (@WildRank_TV).
It uses the YouTube Data API solely to add subtitles and translated titles/descriptions to the channel's own videos.
It does not collect, store, sell or share any data from other users. OAuth tokens are stored as encrypted
GitHub Actions secrets and are used only by this automation. Contact: wildrank.tv@gmail.com
